# Rasika R — Portfolio Website

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Run it locally
1. Extract `rasika_portfolio.zip`.
2. Open `index.html` in a browser.
3. For a local development server, open the folder in VS Code and use the Live Server extension if installed.

## Before publishing
- Open `script.js` and replace the empty `linkedin` and `github` values in `profileLinks` with Rasika's actual public profile URLs.
- Project repository/demo links can be added once the projects are available online.
- The portfolio uses the information provided in the resume. Review dates, project wording, and certification names before publishing.
- No phone number or full residential address is included.

## Publish free with GitHub Pages
1. Create a GitHub repository named `rasika-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

This is a static website; it does not require a backend or API keys. Google Fonts are loaded from the internet, with system font fallbacks.
